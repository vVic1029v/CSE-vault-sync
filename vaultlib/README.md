# vaultlib

One module (`autolib.py`, stdlib only) shared by the vault generators:

- `~/Projects/CSE-vault-sync/brightspace-pipeline` — Brightspace clone
- `~/Projects/CSE-vault-sync/timetable-mirror` — MyTimetable mirror + Courses/ hubs

No install step: consumers insert `../vaultlib` into `sys.path` (see module
docstring) and import. Provides: `AUTO_START` / `AUTO_END` markers,
`split_markers()` (absolute user/generator boundary), file `banner()`,
`read_section()` (user-space reader), `yq()` (YAML quoting),
`make_readonly()` / `make_writable()`, `tags_line()` (autogenerated tags).

Change with care — every consumer's output changes with it. After edits,
rebuild all outputs and run each tool's checks.
