# timetable-mirror

MyTimetable (TU Delft, TimeEdit ICS) → Obsidian `Timetable/` notes.
One note per class instance in a rolling window, with Full-Calendar
frontmatter (`title/date/startTime/endTime`) plus Dataview fields
(`course/room/kind`) and smart links (course note, same-date lecture note).

Prefer the transactional wrapper `../sync.sh` (checkpoint → run all three
mirrors → review → confirm/rollback); the commands below are for
single-mirror work.

## Install

```bash
pip install -r requirements.txt
```

## Use

```bash
export TIMETABLE_ICS_URL='https://mytimetable.tudelft.nl/ical?...'  # personal, never commit
./sync-timetable.sh                                # ~/Documents/OBSIDIAN/holanda/Timetable
./sync-timetable.sh /path/to/Timetable --days-past 14 --days-future 120
```

Re-runs rebuild the folder in place. Only the `## Notes` section of each
note is preserved (matched per occurrence `UID::dateTtime`, so
recurring-series siblings never share annotations; the section runs to the
next `# ` heading or EOF, so `##` subheadings inside are fine); everything
else regenerates. Annotated notes also get `annotated: true`. The folder
stays writable — but only `## Notes` survives a re-sync, so don't rearrange
anything else (calendar drags are reverted too).

## Matching (all deterministic, no fuzzy titles)

- Course: `DESCRIPTION` → `Course code: X`, else `SUMMARY` prefix (`CSE11A`);
  linked to the vault-side `Courses/<Brightspace-dir>` hub (one per
  `/`-separated part).
- Lecture note: the user's own course note's tree-children ending
  ` - YYYY-MM-DD.md` whose date equals the instance date (linked, never
  used as the course link).
- Times: feed is UTC; converted to Europe/Amsterdam. Cancelled and
  all-day entries are skipped.

## Courses/ hubs

`courses.py` (via `sync-courses.sh`) maintains one hub note per Brightspace
course: regenerated AUTO block (meta, Brightspace + Notebook links,
upcoming-classes query) + preserved user space. Hubs nest under the
`! Course Notes` MOC (tag `moc`, `autogenerated/partial`: static head +
all-imported-classes AUTO dataview over `Timetable/`, created/renamed if
missing, body otherwise preserved); hubs for vanished courses are pruned
only when their user space is empty.
